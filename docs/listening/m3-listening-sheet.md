# M3 listening sheet — Saturation, Delay, Reverb (awaiting engineers)

Spec gate: blind A/B against the reference product on five genre-spanning mixes with two engineers; pass when no
engineer reliably prefers the reference. This sheet is the protocol and the record; it cannot be automated.

## Protocol
1. Five mixes: pop vocal, rock band, hip-hop, acoustic/jazz, electronic. Same stems for A and B.
2. Level-match A and B within 0.1 dB LUFS-S on the processed track.
3. Blind, randomised order, 8 trials per plugin per mix; the listener marks preference (A / B / none).
4. A preference is "reliable" when one engineer picks the same product in ≥ 7 of 8 trials.

## Settings under test
| Plugin | Preset | Reference | Notes |
| --- | --- | --- | --- |
| Saturation | Tape · Gentle warmth; Tube · Vocal glow | tape / console emulation (Kramer Tape, J37 or NLS class) | compare at the reference drive and at +12 dB |
| Delay | Dotted eighth · Vocal; Ping-pong · 1/4 | H-Delay class | listen for the slew on time changes and the ducking |
| Reverb | Hall · Concert 2.4 s; Plate · Vocal 1.8 s; Room · Drum 0.6 s | H-Reverb / RVerb / Abbey Road Plates class | match decay by ear first, then by RT60 |
