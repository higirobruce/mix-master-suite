# Architecture decision records

One page per decision, written before the code that depends on it lands. File name `NNNN-title.md`, sections **Status** (Proposed → Accepted → Superseded by NNNN), **Context**, **Decision**, **Consequences**. Numbering is sequential across the project; the roadmap in `docs/superpowers/plans/2026-11-01-suite-roadmap.md` lists the planned ADRs per milestone.
